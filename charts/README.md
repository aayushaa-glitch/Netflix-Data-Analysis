# Netflix Content Analysis

## Overview

This project analyzes Netflix movies and TV shows using Python, Pandas, and Matplotlib.

The analysis explores:

- Movies vs TV Shows
- Top Genres
- Top Producing Countries
- Release Year Trends
- Content Ratings

## Dataset

Netflix Movies and TV Shows Dataset

## Tools Used

- Python
- Pandas
- Matplotlib
- VS Code
- GitHub

## Key Findings

- Netflix contains more Movies than TV Shows.
- International Movies, Dramas, and Comedies dominate the platform.
- The United States and India produce the most content.
- Netflix experienced significant growth after 2015.
- Mature audience content is a large portion of the catalog.
